# Manuscript Alignment in the Image Space

## 1. Problem definition

Given a source text-line image, `Is`, and a target image of the same textual line,
`It`, the goal is to predict a spatial transformation that maps source coordinates
to the target coordinate system. The required output is a newly warped image,
`Ialigned`, for which spatial disagreement with `It` is minimized.

This is an image-registration problem rather than word recognition. A useful model
must therefore generalize to words and writers that were not represented during
training.

## 2. Baseline and its limitation

The initial system followed Madi et al. (2022): YOLO detected word crops, a Siamese
network estimated pairwise word similarity, and Smith-Waterman aligned the two word
sequences. This is a valid image-domain sequence-alignment baseline, but it returns
word correspondences rather than a transformed source image. Its Siamese training
also lacked a word-class-disjoint evaluation split.

The baseline is retained for comparison. The primary proposed system directly
predicts the spatial transformation and returns `Ialigned`.

## 3. Proposed method

### 3.1 Patch-correlation feature encoder

The source and target pass through a shared three-level convolutional feature
pyramid. Each vertical feature-map column summarizes an overlapping local block of
the line. Let the deepest feature maps be `Fs` and `Ft`. Column descriptors are
L2-normalized and compared globally:

```text
C(t,s) = cosine(Ft(t), Fs(s)).
```

A temperature-scaled softmax converts each target column into a distribution over
source columns. The expected source coordinate supplies a coarse horizontal
backward displacement. A positional prior discourages implausibly large matches
without prohibiting them.

### 3.2 Dense flow decoder

The source feature map is warped by the coarse displacement. A U-Net-like decoder
then combines warped source features, target features, source/target skip features,
the coarse displacement and its confidence. It predicts a two-channel residual
field containing horizontal and vertical pixel displacement.

The final dense field is:

```text
u = upsample(u_coarse) + u_residual.
```

The correlation gain and final residual convolution are initialized to zero, so
the initial model is the identity transformation rather than an arbitrary warp.

### 3.3 Differentiable spatial transformer

Flow follows the backward-sampling convention. At every target pixel `x`, the
model predicts the source coordinate that should be sampled:

```text
Ialigned(x) = Is(x + u(x)).
```

`Ialigned` is produced with bilinear `grid_sample`, allowing registration losses to
backpropagate through the transformation.

### 3.4 Objective

The total objective is:

```text
L = lambda_f L_flow
  + lambda_c L_coarse
  + lambda_p L_charbonnier
  + lambda_ssim L_ssim
  + lambda_s L_smooth
  + lambda_m L_monotonic.
```

`L_flow` supervises the dense two-dimensional displacement. `L_coarse` supervises
only horizontal correlation flow. Image losses are weighted toward ink pixels.
Smoothness regularizes neighboring displacements, while monotonicity penalizes
horizontal folding that could reorder characters.

For cross-font pairs, pixel losses are disabled because different handwriting
styles should not match pixel-for-pixel. Their known synthetic flow is still fully
supervised.

## 4. Data preparation

### 4.1 IAM

Line bounding boxes are extracted directly from the IAM XML connected-component
annotations. Splitting is performed by `writer-id`, not by random form or patch.

| Split | Lines | Writers | OOV token rate |
|---|---:|---:|---:|
| Train | 8,101 | 459 | - |
| Validation | 1,460 | 98 | 13.45% |
| Test | 1,783 | 100 | 13.54% |

For each line, the source is placed on a normalized canvas. The target is generated
using a sampled affine and smooth elastic backward field. Since this transformation
is generated by the dataset, dense ground truth is exact.

### 4.2 Cross-font pairs

The word list is divided by identity into 70/15/15 train/validation/test subsets
before images are rendered. A sentence is rendered in two different fonts using
shared semantic word cells, and the target rendering receives a known synthetic
warp. One font is held out from training for style-generalization evaluation.

## 5. Evaluation protocol

The primary metric is endpoint error:

```text
EPE = mean(||u_pred(x) - u_gt(x)||_2).
```

Reported secondary metrics are the fractions of pixels below 1, 3 and 5 pixels of
endpoint error, aligned-image MAE, SSIM and ink-mask Dice. Every table includes an
identity/no-registration baseline. Cross-font evaluation treats EPE as primary;
pixel metrics are shown only as diagnostics.

## 6. Final results

The base mixed model was trained for 30 epochs on IAM lines and cross-font
synthetic pairs. It was then fine-tuned for eight epochs at learning rate 5e-5.
During fine-tuning, 20% of IAM pairs used exact identity geometry and zero
ground-truth flow. Model selection used writer-disjoint validation EPE, followed
by explicit checks for identity stability and genuine cross-writer alignment.

### 6.1 Writer-disjoint IAM test

The test split contains 1,783 lines from 100 writers absent from training. Its
13.54% out-of-vocabulary token rate also demonstrates that the evaluation is not
restricted to memorized training words.

| Metric | Identity baseline | Final registration model |
|---|---:|---:|
| EPE (pixels, lower is better) | 26.5416 | **5.4679** |
| Pixels within 1 px | - | **4.56%** |
| Pixels within 3 px | - | **29.88%** |
| Pixels within 5 px | - | **55.12%** |
| Image MAE (lower is better) | 0.1187 | **0.0913** |
| SSIM (higher is better) | 0.5178 | **0.6832** |
| Ink Dice | - | **0.4732** |

The model reduces flow EPE by 79.40% and image MAE by 23.06% relative to the
identity transformation, while increasing SSIM by 0.1654.

### 6.2 Unseen words and held-out font

The cross-font test contains 1,000 generated pairs drawn from a 1,485-word test
vocabulary that is disjoint from the training vocabulary. Satisfy is held out as
the test font.

| Metric | Identity baseline | Final registration model |
|---|---:|---:|
| EPE (pixels, lower is better) | 26.2298 | **6.5572** |
| Pixels within 1 px | - | **2.30%** |
| Pixels within 3 px | - | **18.18%** |
| Pixels within 5 px | - | **40.92%** |

This is a 75.00% EPE reduction over identity on word identities and a font not
seen during training. Pixel-appearance metrics are not used as the main criterion
here because the two fonts intentionally render different glyph shapes.

Qualitative examples show that the model corrects the dominant horizontal,
vertical, and smooth elastic displacement. Fine stroke-shape differences and gray
padding artifacts remain near some line boundaries, so the result should be
described as strong geometric improvement rather than perfect pixel matching.

### 6.3 Genuine cross-writer IAM pairs

Ten repeated test-set transcriptions were found in IAM, each written by two
different writers absent from training. The XML word boxes provide semantic
landmarks without constructing a synthetic warp. Predicted backward flow is
sampled at each target word center and compared with the corresponding source
word center.

| Real-pair metric | Identity | Selected model |
|---|---:|---:|
| Mean word-landmark error (pixels) | 26.5010 | **10.3408** |
| Landmarks within 5 pixels | - | **23.26%** |
| Landmarks within 10 pixels | - | **65.12%** |

The 60.98% landmark-error reduction is direct evidence of generalization to
genuine handwriting pairs, rather than only inversion of generated warps.

### 6.4 Controlled ablation and identity stability

| Model | IAM EPE | Cross-font EPE | Exact-pair motion | Real landmark error |
|---|---:|---:|---:|---:|
| IAM-only, 30 epochs | 5.7992 | 8.3126 | 2.2337 | 11.2891 |
| IAM + cross-font, 30 epochs | 5.4794 | 6.6387 | 2.3391 | **10.0838** |
| Selected identity fine-tune | **5.4679** | **6.5572** | **0.3231** | 10.3408 |

The controlled IAM-only comparison shows that cross-font training materially
improves held-out-style EPE. Identity fine-tuning reduces spurious exact-pair
motion by 86.19%, improves IAM and cross-font EPE slightly, and incurs a small
2.55% increase in real-pair landmark error relative to the unfine-tuned mixed
model. The fine-tuned checkpoint is selected because it provides the strongest
overall behavior while preserving a 60.98% real-pair improvement over identity.

## 8. Limitations and future work

The dense registration model assumes the two inputs describe the same line content.
Large insertions or deletions require an explicit visibility/unmatched-region mask.
The legacy sequence aligner could provide high-confidence semantic anchors in such
cases. A future hybrid can use those anchors as an auxiliary loss while retaining
the content-independent patch-registration path for unseen words.

Another extension is inverse-consistent bidirectional registration, in which the
source-to-target and target-to-source fields are trained to compose to identity.

At inference time, lines wider than the 512-pixel training canvas are processed
as overlapping 512-pixel blocks. The local dense fields are Hann-weighted and
blended before one full-resolution warp is applied. This preserves the block-based
training scale while avoiding visible seams on long sentences.

A global ink-extent affine prealignment first removes cumulative horizontal and
vertical scale/translation differences that exceed the learned local displacement
range. If `u_a` is the affine backward flow and `u_r` is the neural residual, the
composed field is `u(x) = u_r(x) + u_a(x + u_r(x))`. The original source is sampled
only once with this composed field, avoiding the blur that would result from two
successive image warps.
